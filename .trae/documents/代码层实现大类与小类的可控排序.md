## 现状定位
- 大类（标签）来源：在 `src/components/StyleSelector/index.tsx:20-27` 以常量数组定义；顺序由该数组决定。
- 小类（卡片）来源：在 `src/config/options.ts:3-189` 的 `transformOptions`，按分类过滤后直接展示；当前顺序为原始数组顺序。

## 目标
- 在代码层配置可控的大类顺序（如把“打卡模式”排到前面）。
- 在代码层配置各大类下小类的排序（无需运行时拖拽，也可与拖拽并存）。

## 修改方案
### 1) 抽离并集中管理大类顺序与文案
- 新增 `src/config/categories.ts`：
  - `export type CategoryKey = 'style' | 'location' | 'portrait' | 'celebrity' | 'time_travel' | 'dream_jobs' | 'trendy_hair'`
  - `export const CATEGORY_ORDER: CategoryKey[] = ['style','location','portrait','celebrity','time_travel','dream_jobs','trendy_hair']`
  - `export const CATEGORY_LABELS: Record<CategoryKey, string> = { style: '热门玩法', location: '打卡模式', ... }`
- 在 `src/components/StyleSelector/index.tsx`：
  - 移除内联的 `categories` 常量；改为 `import { CATEGORY_ORDER, CATEGORY_LABELS } from '../../config/categories'`
  - 大类渲染改为 `CATEGORY_ORDER.map(key => CATEGORY_LABELS[key])`
- 调整顺序只需修改 `CATEGORY_ORDER` 的数组顺序，无需动组件代码。

### 2) 给小类增加代码层排序能力
- 在 `src/types/transform.ts` 的 `TransformOption` 增加可选字段：`sortIndex?: number`。
- 在 `src/config/options.ts` 为每个小类设置 `sortIndex`（越小越靠前）。
- 在 `src/components/StyleSelector/index.tsx` 渲染当前分类时：
  - `const opts = getOptionsByCategory(activeCategory).slice().sort((a,b)=> (a.sortIndex ?? 0) - (b.sortIndex ?? 0))`
  - 用 `opts` 进行网格渲染。
- 以后仅通过改 `options.ts` 的 `sortIndex` 即可调整该分类下小类的排序。

### 3) 与拖拽编辑并存（可选）
- 若保留拖拽：
  - 拖拽后的顺序优先级 > 代码层顺序；拖拽未发生时默认使用 `CATEGORY_ORDER` 与 `sortIndex`。
  - 可将拖拽结果写入 `localStorage`，下次加载优先生效。

## 变更位置汇总
- 新增：`src/config/categories.ts`（集中管理大类顺序与显示文案）
- 修改：
  - `src/components/StyleSelector/index.tsx`（改为读取配置的顺序与文案；对小类按 `sortIndex` 排序）
  - `src/types/transform.ts`（在 `TransformOption` 增加 `sortIndex` 字段）
  - `src/config/options.ts`（为小类配置 `sortIndex`）
