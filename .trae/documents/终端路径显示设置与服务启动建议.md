## 问题解答：Trae 终端显示空白与路径配置

Trae 的终端默认使用你系统安装的 Shell（如 PowerShell 或 CMD）。如果显示空白或只有光标，通常有几种原因：
1. **进程卡住**：之前的命令（如 `npm run dev`）还在后台运行但没有输出。
2. **提示符配置**：PowerShell 的 `prompt` 函数可能被重置或默认为空。
3. **显示故障**：IDE 的终端渲染临时故障。

### 如何让终端显示路径（像图2一样）
你可以在 Trae 的终端里输入以下 PowerShell 命令并回车，这会强制重置提示符格式为“当前路径 >”：

```powershell
function prompt { "$PWD > " }
```

或者更标准的 Windows 格式：
```powershell
function prompt { "$($ExecutionContext.SessionState.Path.CurrentLocation)>" }
```

### 关于“跑不了前端”
别担心，我已经帮你尝试在后台启动了前端开发服务器。
如果终端一直无法交互，你可以：
1. 点击终端右上角的 `+` 号新建一个终端窗口。
2. 或者直接点击终端面板右上角的“垃圾桶”图标关闭当前卡死的终端，再重新打开。
